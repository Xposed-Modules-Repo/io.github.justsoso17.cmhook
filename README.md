# CM Hook

网易云音乐的本机 LSPosed 模块。源码与构建说明：https://github.com/justsoso17/cmhook

## 功能

- **消息防撤回** —— 聊天页右下角「撤回 N」胶囊，点开看被撤回的原文（可拖动）
- **首页清理** —— 首页「推荐」只保留想要的内容
- **界面整理** —— 播客「为你推荐」、关注页「乐迷团」、开屏广告
- **听歌识曲** —— 长按首页顶栏搜索区直达
- **其他** —— 独白 HUD、频道保留控制、App 探测清单

## 使用

1. 在 LSPosed 中勾选 **网易云音乐**
2. 重启网易云音乐
3. 设置页右下角「⚙ CM Hook」胶囊 → 逐项开关

## 兼容

- LSPosed（API 82+）· 目标版本 9.5.96 · minSdk 24 / targetSdk 33
- 所有功能都能在模块面板里单独开关
