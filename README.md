# CM Hook

网易云音乐的本机 LSPosed 模块。源码与构建说明：https://github.com/justsoso17/cmhook

## 功能

- **去开屏广告** —— 冷启动直达首页，不再等待或展示开屏广告
- **首页精细控制** —— 顶部卡片行、行内卡片、内容区块单独隐藏；块清单按账号自动发现、直接显示页面文案；内置一键重启生效
- **消息防撤回** —— 聊天页右下角「撤回 N」胶囊，点开看被撤回的原文（可拖动）；只有当本地 database 中存有该消息时才可查看被撤回内容
- **抽屉卡片自定义** —— 抽屉顶部 VIP 挽回卡替换为自定义图片：面板选图 → 裁切编辑页调整，可一键恢复占位
- **界面整理** —— 播客「为你推荐」、关注页「乐迷团」
- **听歌识曲** —— 长按首页顶栏搜索区直达
- **其他** —— 独白 HUD、频道保留控制、App 探测清单

## 使用

1. 在 LSPosed 中勾选 **网易云音乐**
2. 重启网易云音乐
3. 设置页右下角「⚙ CM Hook」胶囊 → 逐项开关

## 兼容

- LSPosed（API 82+）· 实测 9.5.96 / 9.6.0 · minSdk 24 / targetSdk 33
- 所有功能都能在模块面板里单独开关
