# CM Hook

网易云音乐的本机 LSPosed 模块：界面净化 + 消息防撤回 + 协议观测。
源码与构建说明：https://github.com/justsoso17/cmhook

## 功能

### 净化

- **去开屏广告** —— 冷启动直达首页，不再等待或展示开屏广告
- **拦截开屏运营弹窗** —— 「开黑瓜分」式活动弹窗不再跳出来
- **首页精细控制** —— 顶部卡片、内容区块逐项隐藏；块清单按账号自动发现，内置一键重启生效
- **隐藏杂项** —— 「免费听时长」推广横幅、播客「为你推荐」、关注页「乐迷团」、频道保留控制

### 消息

- **消息防撤回** —— 聊天页「撤回 N」胶囊，点开看被撤回的原文与图片：缩略图、点开看大图、长按保存到 Download。台账按当前登录账号视角过滤。
  ⚠️ 图压根没同步到你手机（你从没打开过那个会话）时无法防止撤回，文字同理

### 个性化

- **抽屉卡片自定义** —— VIP 挽回卡换成自定义图片：选图 → 裁切，一键恢复
- **独白 HUD** —— 把接口调用翻译成人话的悬浮窗
- **听歌识曲** —— 长按首页顶栏搜索区直达

### 观测

- **App 探测清单** —— 同源跟随官方名单，实时探测
- **DexKit 锚点自检** —— 对抗版本升级的混淆漂移

## 使用

1. 在 LSPosed 中勾选 **网易云音乐**
2. 重启网易云音乐
3. 设置页右下角「⚙ CM Hook」胶囊 → 逐项开关

## 兼容

- LSPosed（API 82+）· 实测 9.5.96 / 9.6.0 / 9.6.05 · minSdk 24 / targetSdk 33
- 所有功能都能在模块面板里单独开关
